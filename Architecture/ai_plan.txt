# 6. LangGraph Agent Workflow (Very Powerful)

```

     |
Intent Detection
     |
If financial → financial tools
If complaint → complaint tools
If document → RAG search
If notice → notice generator

Tool Execution
     |
LLM Response
```

This is how real AI agents are built.
